# Source and measurement provenance

- Jolt ParComm remains in the repository's original root workspace. The
  eight reference logs are copied verbatim from the project root. The original
  four Jolt logs contain the historical command and acceptance marker; no new
  model timings are claimed by this packaging operation.
- The Jolt model logs used a local source override on the benchmark server. That
  source snapshot is included in `third_party/jolt/`. Its downloaded archive
  SHA256 is `b26d6172875b7ac6323161817d626e485164eb03eacf219ea745a3a0fdf20c80`.
  The server snapshot had no `.git` metadata, so we cannot assert that it is
  byte-identical to the private commit named in the original manifest.
- Pinned arkworks checkout: `76bb3a4518928f1ff7f15875f940d614bb9845e6`.
  Pinned spongefish checkout: `d2d190b1329d35ac9577438d05aed4f17a57b9f9`.
  These required customized sources are bundled under `third_party/`. Public
  registry packages are resolved by Cargo.lock and downloaded by Cargo; optional
  local vendor mirrors are excluded from Git.
- Artifact-only packaging changes replace Git dependency resolution with local
  paths, preserve the project's patched ark-ec in both arkworks workspaces, and
  regenerate the lockfile for those path identities. No Rust implementation
  files are changed. The original local and server lockfiles are retained under
  `validation/` and `third_party/` respectively.
- QAFold sources are copied from `qafold/model_encoding_20261108`, with each
  file verified against its frozen manifest. The KoalaBear source is the same
  implementation used in the prior optimized 70B 16-bit run. The preserved
  source manifests are in `results/reference/`; their original paths refer to
  the historical experiments, not the artifact layout.
- QAFold 8B8/8B16/70B8 measurements come from the November 8 model sweep;
  70B16 comes from the preceding November 8 encoding optimization experiment.
  All four are low-memory, single-invocation, CPU-only runs. Full measurement
  records and proof hashes are retained in `qafold-measurements.json`; large
  proof files remain in the local original experiment evidence, and can be
  regenerated by the model runner. They are not bundled in this compact package.
- Reference environment: Ubuntu 22.04, dual Xeon Gold 6342, approximately
  377 GiB RAM; Python 3.10.12, NumPy 2.2.6. QAFold reference builds used
  `-C target-cpu=native` and Rust 1.95. Artifact local validation uses Rust
  1.97.1 for QAFold and nightly-2026-03-21 for Jolt.

Git identifies the distributed source, with Cargo lockfiles and vendor checksums. Historical
experiment directories, maintenance backups and build caches are excluded by
.gitignore and remain local evidence. Original tracked auxiliary files, including
the GPU workspace, remain in the repository; the supported reproduction entry
point runs CPU implementations only. No model weights or credentials are added.
